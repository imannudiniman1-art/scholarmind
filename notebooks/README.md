# ScholarMind Notebooks

This directory contains experimental notebooks
for exploring and demonstrating ScholarMind.

## Planned Notebooks

### 01 - ScholarMind Demo

Demonstrates:

- Loading research data
- Creating research papers
- Searching research knowledge
- Exploring the Knowledge Graph
- Using the Research Assistant

### 02 - Research Metadata Exploration

Explores:

- DOI
- Abstract
- Keywords
- Methodology
- Dataset
- Findings
- Source

### 03 - Knowledge Graph Exploration

Demonstrates research entities and relationships.

## Purpose

Notebooks are used for experimentation, visualization,
prototyping, and research analysis.

Production logic should remain inside the `src/`
directory.
